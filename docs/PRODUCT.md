# 产品说明（审核材料）

## 项目定位

基于 58同城开放平台数据的**本地生活信息服务应用**，提供招聘、房产、二手车、本地服务四大业务线的信息聚合检索能力，支持按城市（如衡阳）定向筛选。

## 目标用户

- 衡阳及湖南本地求职者、租房购房用户、二手车买家
- 需要本地生活服务信息聚合的 C 端用户

## 核心功能（规划）

1. 本地信息检索：按城市 + 分类查询招聘/房产/二手车/本地服务信息
2. 城市定向：支持城市编码（city_id）精确筛选，优先覆盖衡阳
3. 信息详情：查看单条信息完整内容
4. 数据聚合：多分类汇总统计，输出本地生活数据洞察

## 技术架构

- 前端：Web 单页应用（HTML/JS）
- 后端：Python Flask API 网关
- 数据源：58同城开放平台（open.58.com / openapi.58.com）

## 商业模式（规划）

- 信息聚合展示（免费）
- 数据洞察报告 / 增值服务（收费，规划中）
